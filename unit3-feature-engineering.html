TOPIC 3.1

Sentiment Analysis & Opinion Mining

Classifies text into positive, negative, or neutral tones. Rule-based systems (VADER) use sentiment dictionaries with valence rules. Supervised ML models (Naïve Bayes, Logistic Regression) learn patterns from labeled customer reviews.

💡 ELI5 Analogy: Rule-based sentiment is like a robot carrying a dictionary with score points (+1 for 'awesome', -1 for 'terrible'). ML sentiment is like a child watching 1,000 movies and learning when someone is sarcastic or angry!
PYTHON PRACTICE: VADER SENTIMENT
from nltk.sentiment.vader import SentimentIntensityAnalyzer import nltk nltk.download('vader_lexicon') sia = SentimentIntensityAnalyzer() text = "Service was breached, but support was amazingly quick!" scores = sia.polarity_scores(text) print("Compound Polarity Score:", scores['compound']) # Output: Compound Score: +0.435 (Overall Positive)
TOPIC 3.2

Topic Modeling (LDA) & Classification

Latent Dirichlet Allocation (LDA) is an unsupervised probabilistic model that discovers hidden thematic topics across documents. It represents each document as a distribution of topics ($\theta$), and each topic as a distribution of words ($\phi$).

💡 ELI5 Analogy: Imagine dumping 500 unorganized storybooks onto the floor. LDA Topic Modeling is a magical sorting hat that scans all pages and groups them into 3 piles: Wizards, Space Rockets, and Dolphins without reading titles!
PYTHON PRACTICE: GENSIM LDA
from gensim import corpora from gensim.models import LdaModel # Unsupervised Corpus of Support Tickets docs = [['refund', 'delivery', 'late'], ['billing', 'charge', 'invoice'], ['refund', 'money']] dictionary = corpora.Dictionary(docs) corpus = [dictionary.doc2bow(doc) for doc in docs] lda = LdaModel(corpus, num_topics=2, id2word=dictionary, passes=10) for idx, topic in lda.print_topics(): print(f"Topic {idx}: {topic}")
TOPIC 3.3

Named Entity Recognition (NER) & Summarization

NER identifies structured real-world entities (Companies, Monetary Values, Dates, Locations) using spaCy models. Text Summarization compresses documents via Extractive (selecting key sentences) or Abstractive (generating new text) methods.

💡 ELI5 Analogy: NER is putting highlighter pens on a textbook: Pink for Company names (Apple), Green for Money ($5M), Yellow for Dates. Summarization is telling your best friend a 100-page comic book story in 2 minutes!
PYTHON PRACTICE: SPACY NER
import spacy nlp = spacy.load("en_core_web_sm") doc = nlp("Apple Inc. spent $50 million in New York on Q3 2026.") for ent in doc.ents: print(f"Entity: {ent.text:<15} | Tag: {ent.label_}") # Output: Apple Inc. -> ORG | $50 million -> MONEY | New York -> GPE
TOPIC 3.4

Assembling the Master Feature Matrix

The core goal of Unit 3 feature engineering is combining TF-IDF sparse matrices + VADER sentiment scores + NER entity counts + LDA topic distributions into a single unified Pandas DataFrame for machine learning models.

💡 ELI5 Analogy: Feature engineering is combining flour (words), sugar (sentiment), and chocolate chips (entities) into one master baking tray (DataFrame) so your machine learning oven can bake a perfect prediction!
PYTHON PRACTICE: FEATURE MATRIX
import pandas as pd from sklearn.feature_extraction.text import TfidfVectorizer from nltk.sentiment.vader import SentimentIntensityAnalyzer df = pd.DataFrame({'text': ["Refund breached SLA!", "Great product quality!"]}) sia = SentimentIntensityAnalyzer() # Extract Numeric Features df['sentiment_score'] = df['text'].apply(lambda x: sia.polarity_scores(x)['compound']) df['word_count'] = df['text'].apply(lambda x: len(x.split())) df['exclamation_cnt'] = df['text'].apply(lambda x: x.count('!')) print(df)

QUESTION 1 OF 4

What is the key difference between VADER rule-based sentiment analysis and Supervised Machine Learning sentiment models?

Correct Answer! VADER is a lexicon and rule-based sentiment model that uses pre-built word scores and valence rules (e.g. capitalization, negation). Supervised ML requires training datasets with positive/negative labels.
QUESTION 2 OF 4

In Latent Dirichlet Allocation (LDA) Topic Modeling, what does the document-topic distribution ($\theta$) represent?

Correct Answer! In LDA, documents are treated as mixtures of topics. The distribution $\theta$ assigns a probability score to each topic for a specific document (e.g., Document 1 is 70% Billing, 30% Tech Support).
QUESTION 3 OF 4

Which Named Entity Recognition (NER) tag would spaCy assign to "$500,000" in a corporate financial report?

Correct Answer! spaCy tags monetary values including currency symbols and numeric amounts ($500,000, €10M) as MONEY.
QUESTION 4 OF 4

What is the primary distinction between Extractive and Abstractive Text Summarization?

Correct Answer! Extractive summarization identifies and pulls high-scoring original sentences (e.g. TextRank). Abstractive summarization generates new phrasing using sequence-to-sequence neural networks (e.g. BART, T5).

FLASHCARD 1

What are Valence Shifters in Sentiment Analysis?

Valence shifters are words that alter the sentiment score of neighboring terms. They include Negations ('not good' flips + to -), Intensifiers ('extremely happy' boosts score), and Diminishers ('barely acceptable' lowers score).
FLASHCARD 2

How does Coherence Score ($C_v$) evaluate LDA Topic Models?

Topic Coherence measures how semantically readable and human-interpretable a topic's top words are. A higher $C_v$ score (closer to 0.7+) indicates well-separated, meaningful business topics.
FLASHCARD 3

What is BIO Tagging in Named Entity Recognition?

BIO tagging marks multi-word entities: B (Begin entity token, e.g. 'B-ORG' for New), I (Inside entity token, e.g. 'I-ORG' for York), and O (Outside any entity).
FLASHCARD 4

Why combine Text Surface Features with Sentiment & Entities?

Combining word counts, exclamation ratios, VADER sentiment, entity counts, and LDA topics creates a rich 360° feature vector that boosts model performance for churn prediction and priority ticket routing.

# ============================================================================== # 24INFS7101 - UNIT 3: FEATURE ENGINEERING & TEXT MINING MASTER PIPELINE # ============================================================================== import pandas as pd import numpy as np import nltk import spacy from nltk.sentiment.vader import SentimentIntensityAnalyzer from sklearn.feature_extraction.text import TfidfVectorizer from gensim import corpora from gensim.models import LdaModel # Download required NLTK & spaCy assets nltk.download('vader_lexicon') nlp = spacy.load("en_core_web_sm") # Sample MBA Customer Review Dataset corpus_data = [ "URGENT: Our Service Level Agreement (SLA) with Apple Inc. was breached! Immediate refund of $50,000 required.", "Great product quality from Google in New York. Delivery was fast and customer service was helpful.", "Poor support and late delivery! Return on investment dropped by 30%. Unsatisfied with service." ] df = pd.DataFrame({'raw_text': corpus_data}) # 1. SENTIMENT ANALYSIS (VADER) sia = SentimentIntensityAnalyzer() df['vader_compound'] = df['raw_text'].apply(lambda x: sia.polarity_scores(x)['compound']) df['sentiment_class'] = df['vader_compound'].apply(lambda s: 'POSITIVE' if s >= 0.05 else ('NEGATIVE' if s <= -0.05 else 'NEUTRAL')) # 2. NAMED ENTITY RECOGNITION (NER - spaCy) def extract_entities(text): doc = nlp(text) orgs = [ent.text for ent in doc.ents if ent.label_ == 'ORG'] money = [ent.text for ent in doc.ents if ent.label_ == 'MONEY'] return len(orgs), len(money) df[['org_count', 'money_count']] = df['raw_text'].apply(lambda x: pd.Series(extract_entities(x))) # 3. TEXT SURFACE FEATURES df['char_length'] = df['raw_text'].apply(len) df['word_count'] = df['raw_text'].apply(lambda x: len(x.split())) df['urgency_flag'] = df['raw_text'].apply(lambda x: 1 if 'URGENT' in x.upper() or 'BREACHED' in x.upper() else 0) # 4. LDA TOPIC MODELING (Gensim) tokenized_docs = [doc.lower().split() for doc in corpus_data] dictionary = corpora.Dictionary(tokenized_docs) gensim_corpus = [dictionary.doc2bow(doc) for doc in tokenized_docs] lda = LdaModel(gensim_corpus, num_topics=2, id2word=dictionary, passes=10) def get_top_topic(text): bow = dictionary.doc2bow(text.lower().split()) topics = lda.get_document_topics(bow) return max(topics, key=lambda x: x[1])[0] df['primary_topic_id'] = df['raw_text'].apply(get_top_topic) print("=== FINAL UNIT 3 FEATURE MATRIX ===") print(df[['raw_text', 'vader_compound', 'sentiment_class', 'org_count', 'money_count', 'urgency_flag', 'primary_topic_id']])
